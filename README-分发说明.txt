填表工具 · macOS 版分发说明
================================================

本文件夹「填表工具-mac」用于把填表工具发给苹果(Mac)用户。
有两种做法，任选其一（推荐方案A，用户体验最好）。


------------------------------------------------
方案A：GitHub 云端自动打包成 .app（推荐）
------------------------------------------------
产出：一个原生「填表工具.app」，Mac 用户拖进「应用程序」双击即用，
     无需安装 Python、无需任何命令行。

步骤：
1. 注册/登录 github.com，新建一个仓库（Repository），建议设为 Public（私有也行，走免费额度）。
2. 把本文件夹「填表工具-mac」里的【全部内容】（含隐藏的 .github 文件夹）上传到该仓库根目录。
   - 注意 .github 是以点开头的隐藏文件夹，上传时别漏掉。
3. 打开仓库 → 顶部 Actions 标签 → 左侧「构建 macOS 填表工具」→ 右侧「Run workflow」→点绿色按钮。
   （或直接 push 一次也会自动触发）
4. 等约 5-10 分钟跑完，点进这次运行，在页面底部 Artifacts 里下载：
     - 填表工具-macOS-arm64   → 给 Apple 芯片(M1/M2/M3/M4)的用户
     - 填表工具-macOS-x86_64  → 给老 Intel 芯片的用户
5. 把对应 zip 发给用户；解压得到「填表工具.app」，拖进「应用程序」即可。

如何确认对方芯片：苹果菜单  →「关于本机」→ 芯片一栏写 Apple M 系列=arm64；写 Intel=x86_64。


------------------------------------------------
方案B：直接发源码包（不打包，需对方有 Python）
------------------------------------------------
产出：把本文件夹压缩发给用户，对方双击 run.command 自动装依赖并启动。
适合：对方懂一点电脑、或临时用一次。

步骤：
1. 把整个「填表工具-mac」文件夹压缩成 zip 发给用户。
2. 用户解压后，双击 run.command：
   - 首次会自动创建虚拟环境并安装依赖（约1-2分钟），随后启动界面。
3. 若双击没反应或被拦截：打开「终端」，输入
     bash 后空格，把 run.command 拖进终端窗口，回车。

前提：对方电脑装有 Python3，且该 Python 带 Tkinter 图形库。
   最省事：去 https://www.python.org/downloads/ 下载安装包版 Python（自带图形库）。
   注：Mac 自带的 python3 常缺图形库，脚本会提示并给出安装办法。


------------------------------------------------
关于「已损坏/无法打开」的提示（方案A 常见）
------------------------------------------------
未经苹果付费签名公证的 .app，首次打开可能被 Gatekeeper 拦截。让对方任选其一：
 - 对着 App「右键(或双指点按) → 打开 → 再点打开」；
 - 或 系统设置 → 隐私与安全性 → 点「仍要打开」；
 - 或 终端执行：  xattr -dr com.apple.quarantine "/Applications/填表工具.app"


------------------------------------------------
功能可用性（Mac 上）
------------------------------------------------
- ①-⑯ 全部文档/表格/PPT/HTML/办公工具功能：正常可用。
- ⬓ 视频合成、⬔ 去水印：依赖 ffmpeg，已随包内置，正常可用。
  （去水印的“照片智能修补”需 opencv，Mac 未打包时会自动回退“淡化去除”，仍可用。）
- 界面为 tkinter 原生控件，Mac 上外观与 Windows 略有差异，功能一致。
